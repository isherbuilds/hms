# Glossary

Canonical terms for the HMS product. One term per concept; synonyms listed only to ban them.

- **Organization** — one hospital tenant (Better Auth organization). Never "team", "workspace", "account".
- **Member** — a staff user inside an Organization (Better Auth member).
- **Patient** — the person receiving care. Belongs to one Organization (no cross-hospital identity in MVP; ABDM/ABHA linkage later).
- **Visit** — one patient arrival lifecycle (FHIR: Encounter). Classes: **OPD** (outpatient), **IPD** (inpatient/admitted), **ER** (emergency). Not "appointment" (an Appointment may create a Visit; walk-ins create Visits directly).
- **OPD** — outpatient department flow: registration → queue → consult → bill/receipt on the spot.
- **IPD** — inpatient flow: admission → bed occupancy → orders/nursing → discharge (ADT).
- **Order** — a practitioner request within a Visit (FHIR: ServiceRequest for lab/radiology/procedure; MedicationRequest for drugs).
- **Charge** — a billable line generated by registration, consult, order, bed-day, or pharmacy sale. Charges accumulate on the Visit.
- **Invoice / Receipt** — Invoice: GST-classified bill for a Visit's charges. Receipt: proof of payment. Both printable on the spot at OPD.
- **Billing vs Accounting** — the HMS owns Billing (charges, invoices, receipts, GST, collection reports). **Accounting (ledger) stays external** — Tally or equivalent; the HMS exports vouchers/day-book. We never build a general ledger.
- **Service Unit** — a node in the facility tree: campus > ward > room > bed (Frappe Health term, kept).
- **MRN** — Medical Record Number: per-Organization sequential patient identifier, assigned at first registration. Dedupe by phone number + name at registration time.
- **Service Catalog** — the Organization's priced list of billable services (consult fees, procedures, lab tests), each with a GST class. Charges reference catalog items.
- **Provenance Envelope** — shared metadata on AI-draftable content: `generatedBy` (Member | AI), model + version, reviewer, timestamps. Replaces the earlier universal "Draft → Approve" idea; each aggregate keeps its own explicit state machine (Invoices: immutable + credit note; Charges: pending → invoiced | voided). A paper prescription is a source document, not AI-draftable content.
- **Credit Note** — the only correction mechanism for an issued Invoice; carries line-level tax snapshots (GST breakup). Invoices are never edited or "unapproved".
- **Refund** — money returned to a Patient, always recorded against a Credit Note (methods: cash/UPI/card, own number series). Caps at recording time: amount ≤ current refund-due (`max(0, −outstanding)`) and cumulative refunds per Credit Note ≤ that note's total. Payments likewise cap against current positive outstanding. `outstanding = grandTotal − credits − payments + refunds`; negative outstanding renders as "refund due".
- **Tally Export** — day-book voucher export (Tally XML) from billing data. The boundary artifact between HMS Billing and external Accounting.
- **Practitioner** — doctor/clinical staff member with a schedule and consult fee (FHIR: Practitioner).
